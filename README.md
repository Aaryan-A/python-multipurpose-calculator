# Python Multipurpose Calculator

A Python calculator for unit conversions, simple interest, and annual salary estimation.

## Features

* **Height Conversion:** Converts feet and inches to centimeters.
* **Weight Conversion:** Converts pounds to kilograms.
* **Simple Interest:** Calculates interest based on principal, interest rate, and time.
* **Annual Salary Estimation:** Estimates annual earnings based on hourly wages and weeks worked per year.

## Technologies Used

* Python
* Functions
* Lists
* Loops
* Conditional Statements
* User Input and Output

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the code.
3. Select a calculation from the menu.
4. Enter the requested values to view the result.
